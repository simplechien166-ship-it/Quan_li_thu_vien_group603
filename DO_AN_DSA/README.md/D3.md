# BÁO CÁO D3
## THIẾT KẾ VÀ CÀI ĐẶT

## 1. Kiến trúc hệ thống

Hệ thống được tổ chức thành ba tầng:

1. **Presentation Layer:** `CLI.cpp`, `main.cpp` và giao diện `Web/index.html`.
2. **DSA Core Layer:** `LibraryManager`, `CustomHashTable`, `ReservationQueue`, `CustomMinHeap`.
3. **Persistence Layer:** `PersistenceManager` đọc và ghi dữ liệu CSV.

## 2. Các cấu trúc dữ liệu

| Cấu trúc | Vai trò | Độ phức tạp trung bình |
| :--- | :--- | :---: |
| Custom Hash Table | Tra cứu sách, độc giả và chỉ mục phiếu mượn. | O(1) |
| Borrow Index | Ánh xạ `MaPhieu` tới vị trí trong danh sách phiếu. | O(1) |
| ReservationQueue | Xếp hàng chờ mượn theo FIFO. | O(1) |
| Custom Min-Heap | Duy trì Top 10 sách được mượn nhiều nhất. | O(N log K) |
| Vector | Lưu danh sách phiếu và lọc dữ liệu. | O(N) |

## 3. Luồng mượn sách

1. Tìm độc giả bằng mã độc giả.
2. Kiểm tra trạng thái thẻ.
3. Tìm sách bằng mã sách.
4. Nếu còn sách, giảm số lượng còn lại và tăng lượt mượn.
5. Nếu hết sách, thêm độc giả vào `ReservationQueue`.
6. Tạo phiếu mượn và cập nhật `Borrow Index`.

## 4. Luồng trả sách

1. Tra cứu phiếu bằng `Borrow Index`.
2. Kiểm tra phiếu chưa được trả.
3. Tính số ngày quá hạn bằng thuật toán chuyển ngày.
4. Cộng tiền phạt và khóa thẻ nếu nợ đạt ngưỡng.
5. Nếu có người chờ, tự động tạo phiếu mới cho người đầu hàng đợi.
6. Nếu không có người chờ, tăng số lượng sách còn lại.

## 5. Lưu trữ và kiểm tra dữ liệu

Dữ liệu được lưu trong:

- `data/books.csv`
- `data/readers.csv`
- `data/borrows.csv`

`PersistenceManager` kiểm tra định dạng số, ngày tháng, mã trùng, số lượng sách, trạng thái thẻ và khóa ngoại giữa phiếu mượn với sách và độc giả.

## 6. Giao diện

CLI hỗ trợ tra cứu, mượn, trả, báo cáo quá hạn, Top 10, hiển thị danh sách và lọc sách theo năm. Web API cung cấp danh sách sách, độc giả, Top 10 và báo cáo quá hạn tại cổng 8080.
