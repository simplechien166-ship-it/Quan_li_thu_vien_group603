## 3. Benchmark

Benchmark dùng `std::chrono` với các mức 1.000, 10.000 và 100.000 bản ghi.

| N | Linear MC1 | Hash MC1 | Range MC2 | Top 10 | Queue |
| :---: | ---: | ---: | ---: | ---: | ---: |
| 1.000 | 1.222 ms | 0.042 ms | 0.001 ms | 0.123 ms | 0.031 ms |
| 10.000 | 129.895 ms | 0.685 ms | 0.026 ms | 0.367 ms | 0.032 ms |
| 100.000 | 18,610.339 ms | 20.208 ms | 0.602 ms | 3.139 ms | 0.034 ms |

Linear Search tăng theo chi phí O(N²) khi thực hiện N lần tìm kiếm, trong khi Hash Table có chi phí trung bình O(1) cho mỗi lần tra cứu.
